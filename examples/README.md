# 整套跨行业教学案例

这里的数字、机构与计划全部为合成材料，用于展示论证与版式选择，不代表真实研究发现或经营效果。两套案例各6页，都使用统一源数据绑定关键金额、条件、推荐及标题。

| 案例 | 要支持的决定 | 主要表达关系 |
|---|---|---|
| [客服投入](saas-budget/README.md) | 是否批准有限范围的知识库试点 | 趋势、同口径比较、阶段验证、预算分解 |
| [共享研究服务](university-service/README.md) | 两院系能否启动共享服务试点 | 需求分类、范围与投入、同时满足的准入条件、分阶段复核 |

每套包含 `source.json`、`storyboard.md` 和说明。先读简报与数据，再看逐页职责；不要只换标题复用内容。生成的PPT与预览若随仓库提供，仍应以对应检查记录区分机器校验、逐页视觉、编辑重开和目标应用范围。

这两套是公开教学材料，执行者已经见过它们后不能再把它们作为迁移盲测。未见任务与独立评价流程见[任务评测](../references/evaluation.md)。
