# 任务分支与完成条件

先从用户请求和已有上下文提取任务、输入文件、受众、用途、输出目的地、页数与修改范围。低影响缺项使用明确假设；缺失事实会改变结论时，保留未知或提出最少的问题，同时推进不依赖该事实的工作。无需为每个分支新建一套文件；工作记录保存在本次项目目录，按用户要求交付。

## 学习样本 `learn`

适用于解释原页、学习故事线、比较布局及选择表达方式。读取[来源索引](corpus-map.md)与问题涉及的[故事线](storyline-patterns.md)、[版式](layout-patterns.md)或[图表](professional-chart-design.md)部分；只在数字制造分析确有需要时读取制造方法。

完成时说明页面职责、观点与证据、视觉关系、前后衔接及何时不适用，标明文件编号和物理页序。直接观察、归纳和待验证判断分别表达。只看到截图时，不能声称核对了原文件、备注或可编辑对象。

## 故事板 `storyboard`

适用于目录、逐页提纲、标题链和灰度布局草案。读取[故事线](storyline-patterns.md)与[质量标准](quality-rubric.md)中逻辑、事实部分；需要具体表达时再查布局。

每页至少有页面任务、标题、需要证明的判断、证据或缺项、视觉关系及前后衔接。先只读标题检查推进，再核对每项判断是否由正文支持。事实不足时保留暂定标题和补证计划。完成条件是故事板覆盖请求范围且证据缺项可追踪；此分支不自动生成PPT或声称可编辑性已验收。

## 新建成品 `create`

适用于从简报、资料或模板制作新文件。读取故事线、[视觉系统](visual-system.md)、[工具能力](agent-compatibility.md)和[交付检查](production-checks.md)。实际使用T模板、A布局、XY图或数据联动时，再分别读取对应参考；不预先载入全部库。

先确认可用的创建、备注、图表/工作簿、导出和渲染能力，再确定工具路径。使用[样式配置](style-profiles.md)选择品牌与阅读场景，核对字体和容量。完成文件后从最终文件取证，分别记录结构/数据、内容、视觉、编辑重开和目标应用结果。机器构建通过不会自动完成其余验收。缺工具时明确尚未生成的交付物，并保留可继续制作的故事板、源数据与模板。

## 审查 `review`

适用于评判逻辑、设计或成品可靠性。读取质量标准；收到实际成品时再按交付检查验证可检查的项目。每条发现包含页码或对象、具体证据、对读者判断或使用的影响、修改建议，优先列出会改变结论、遗漏限制或妨碍阅读的问题。

审查范围可能只包含叙事、截图或部分页面。结论明确已检查范围和未取得的证据，不将未检查项默认通过。纯审查请求交付发现；同一请求已授权修改时，进入 `edit`，无需另设确认步骤。

## 局部修改 `edit`

适用于替换数字、修改某页、调整品牌或更新既有PPT。读取交付检查；涉及数字时加[数据绑定](data-binding.md)，涉及布局或样式时只读相关规则。

1. 保存原文件或源数据的独立副本，记录要改的页、对象及范围。已有文件的品牌、页序、页数和模板优先；单页任务不追加封面。
2. 列出修改的直接依赖：图表值、工作簿、直接标签、表格、合计、标题、推荐、强调理由、来源及备注。数值改变可能需要重判预算、排序或可执行条件，不能只做文字替换。
3. 在副本实施指定修改。保留未涉及页面、真实源工作簿及公式来源、备注、链接和仍需使用的对象关系。若工具会丢失这些信息，先保留原件并换用可保留的路径；确实无法完成时报告具体限制，不能把全篇重建描述成无损局部编辑。
4. 从修改后的最终文件核对指定对象及全部受影响的依赖，再与原件比较未涉及范围。仅检查改变过的页面不足以证明跨页结论已同步；同样无需把单字修改扩展成未授权的全套重排。

完成时能指出实际修改、依赖回归结果和未执行验证。直接修改PowerPoint对象与修改源JSON后重建是两种更新路径；后者只同步已有绑定，不恢复自由手改的额外内容。使用新输出文件名，保留原件。

## 验收状态与证据

构建结果中的 `checks` 按 `structureData`、`content`、`visual`、`editReopen`、`targetApplication` 分项记录，每项使用 `passed`、`failed` 或 `not_run`，并关联证据。`machine_checks_passed` 表示机器检查完成，`verified` 仅在所有要求均通过后使用；工具不可用的项目保留 `not_run`。范围较小的任务由检查记录说明哪些要求适用，不能借此把未执行验证写成通过。

需要评估Skill本身时，使用[固定任务与盲测流程](evaluation.md)，保留首次运行与修复后的结果。学习样例和已知答案不能作为新的盲测成绩。
