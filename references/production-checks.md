# 可编辑成品的交付检查

制作或审查最终文件时使用。遵循当前演示文稿工具的导出与验证要求；记录检查对应的具体文件及范围，不沿用旧作品的通过结果。

## 导出前

- 确认页数、固定封面、目的地和原生可编辑要求；新主题不残留模板占位、旧行业内容或官方署名。
- 屏幕保留判断所需的事实状态、费用边界、审批权及进入/退出条件；细则进入本页实际备注。
- 图表、表格、标签、正文、标题与推荐共用计算结果。更新后重判条件，不仅替换数字；阈值保留指标与比较分母。
- 新建字面量图表可使用完整数据快照。编辑已有图表时保留真实源工作簿及公式来源，不以新快照冒充恢复。

## 从最终文件取证

| 检查 | 动作与通过证据 |
|---|---|
| 结构与数据 | 核对页数、原生对象、真实备注、来源、字体；逐项比较图表缓存、嵌入xlsx与表格，声明需要检验的合计与比率 |
| 内容 | 标题得到正文支持；事实/测算/目标有区别；对象、单位、周期、分母和权限一致；目录与展开编号对应 |
| 视觉 | 重新渲染全部页面，逐页全尺寸查看，再看全套节奏；检查局部裁切、字体替换、标签与刻度、单元格留白及连线端点 |
| 修改行为 | 独立副本修改文字、单元格、图表值与适用流程节点，导出、重开、提取和渲染，确认对象未被整体扁平化 |
| 目标应用 | 可用时在PowerPoint等实际目的地检查显示与代表性编辑；不可用时记录限制，不把运行库测试写成应用内通过 |

## 容易被结构检查漏掉的问题

- 文字框在画布内，仍可能越出深色容器，反白末行变得不可见；分别核对画布、框、背景与文字。
- 例外连线要连接明确节点，走空白区域；不能用悬空虚线代替未画出的处理步骤。
- 横向条图的API轴名未必与视觉方向一致；检查实际导出的刻度、条长、正负号和单位。
- 双行表头与正文需要实际行高。推荐行的背景和强调条应使用相同几何，不能只通过行数预检。
- 图中数值能改，不代表嵌入工作簿已保留。检查xlsx、图表关系与`externalData`三者；同步缓存和真实单元格。
- 资料不足时保留未知或明确假设，不绘制“已成功”的模拟曲线。建议、批准、暂停等权限跨页核对。

发现问题后修复并重验，保留证据在本次项目的工作目录，活动Skill只保留可复用规则。图表编辑与兼容细节见[专业图表设计](professional-chart-design.md)，持续改数见[数据绑定](data-binding.md)，内容与视觉评价见[质量标准](quality-rubric.md)。
