# 从九份样本学习咨询报告的分析与表达

本轮核心样本为用户精选的9份PPT，共277页。文字分析覆盖全部页面；视觉覆盖、预览方式及兼容性例外以 [样本索引](corpus-map.md) 记录为准。下文页码均为从封面开始的文件页序，包含目录和附录，可能与页脚编号不同。文件编号链接通向索引中的完整路径。

这套方法库提炼的是样本中可观察、可解释、可复用的做法。它帮助你理解报告如何支持判断，并为后续制作提供选择依据；不能据此还原麦肯锡全部内部研究和审稿规范。

## 一、分四层学习

### 分析方法：怎样从问题走到行动

先写清读者要作的决定，再识别影响决定的条件。例如选择先推进哪些站点，既要看价值集中在哪里，也要看数据、人员及实施依赖：[878538 p28–31](corpus-map.md#878538)。高价值不自动等于可以马上实施。

分析表应能回答：解决谁的什么问题、改善哪个指标、方案靠什么机制生效、依赖哪些条件、怎样检验。项目定义页把这些关系写得很具体：[894136 p21](corpus-map.md#894136)。先学习这些字段之间的因果和约束关系，再决定是否需要矩阵或其他框架。

将事实、判断与假设分开。原样本中的收益可能是已实现、已识别、目标、预期或示意，不能因为数字醒目就改变其状态。组织人数、技术架构和投入周期也依赖场景：[894149 p14–15](corpus-map.md#894149) 先列假设，再给组织示例，值得保留这一顺序。

### 整篇行文：怎样让读者一步步形成判断

同一批材料有不同开篇。合作方案先讲阶段、产物与责任；观点介绍先交代变化及机会；操作指南先限定范围，再展开工作方法。因此先判断用途，再选择目录。

可以从这些连接关系学习：机会之后解释实现障碍，障碍之后提出方法；总览之后按相同编号展开；案例之后说明适用条件；路线图之后落实责任与持续运行。对照 [898601 p5–12](corpus-map.md#898601)、[890391 p10–21](corpus-map.md#890391) 和 [912721 p29–33](corpus-map.md#912721)。

只读每页标题，检查能否理解论证推进；再问每一页为下一页解决了什么疑问。目录、定义、联系人可以使用主题标题，有证据支持的发现页才需要明确判断。不能靠把所有标题改成长句来制造逻辑。

### 单页表达：怎样让观点与证据对应

每页先写一个任务，如比较选择、解释机制、证明机会或安排实施，再写标题和证据。案例可以用情境、做法、影响和条件帮助比较：[879680 p7–8](corpus-map.md#879680)。技术页则需要解释设计选择怎样满足业务目标：[898601 p26](corpus-map.md#898601)。

检查标题中的每个关键判断是否在页面上有证据，图表中的主要发现是否在标题或旁注中得到解释。保留对象、时间、单位、基准与来源。预测表现、变量重要性、运营改善属于不同问题，不能相互替代：[912721 p22](corpus-map.md#912721)。

### 视觉：怎样用排版表现关系

稳定的标题区、正文区、页脚与对齐线，让不同内容共享阅读秩序。样本主题常见Georgia标题、Arial正文，部分内容页侧边距约为画布宽度4.5%；这些是观察到的起点，不是新作品必须遵守的统一数值。

正文布局由分析关系决定：比较用对齐的列，评价用有标准的表，交接用泳道，时序用时间线，案例用重复字段。对照 [894136 p19](corpus-map.md#894136)、[910309 p14](corpus-map.md#910309)、[894149 p13、35](corpus-map.md#894149)。颜色用于类别、状态或强调，必须保持图例和跨页含义清楚。

留白应帮助理解，密集页应适合近距离阅读。制作中文页面时先删减、拆页和重写，再调整字号。保留可编辑的图表、表格及流程对象；字体层级和阅读顺序可以迁移，原机构标识及人员资料不应成为默认素材。

## 三、用四轮练习代替被动看模板

第一轮只读标题和目录，为每份写一句“谁读、要决定什么、如何推进”。第二轮挑一个关键判断，沿页面追溯证据、条件和下一步。第三轮画灰度草图，仅保留标题、列、图、标注和阅读方向，解释为什么需要这种结构。第四轮换一个主题，重写论证和内容，再选择版式。每轮都记录“来源页、观察到的做法、为何有效、何时不适用”。

不要先积累大量好看的页面。先能说明一个页面解决了什么问题，再把它加入自己的版式库。

## 四、三个自拟练习

以下均为训练题，不包含真实新项目结果或收益数字。缺少证据的地方写明待验证问题。

### 练习1：为高校设计共享AI支持中心

输出一页设计边界说明和一组报告标题。先说明服务对象、业务单元仍保留的责任，再列组织设计所依赖的假设；暂不填写人数。对照 [894149 p2、13–15、21](corpus-map.md#894149) 与 [890391 p10–11](corpus-map.md#890391)。

检查目标：各项现状与目标是否逐行对应；推荐组织是否能追溯到假设；总览术语是否与展开标题一致；是否清楚标出需要调查的事实。

### 练习2：决定连锁书店先改进哪些门店流程

输出一张优先级分析表和一页实施顺序草图。列出价值、可实施性、数据条件与依赖，不填未经调查的分数；说明需要向门店收集什么资料，以及不同证据可能怎样改变排序。对照 [878538 p28–31](corpus-map.md#878538)、[898025 p7–8](corpus-map.md#898025) 与 [912721 p29–31](corpus-map.md#912721)。

检查目标：商业价值与准备度是否分开评价；顺序是否考虑前置条件；实施后由谁维护、如何复核是否有交代；色块是否没有冒充实际测算。

### 练习3：向管理层解释一个复杂流程的改进建议

自选熟悉的流程，制作三页草图：现状及问题、目标流程及例外处理、实施与检验安排。对照 [910309 p14、17–19](corpus-map.md#910309)、[879680 p7](corpus-map.md#879680) 与 [898601 p26](corpus-map.md#898601)。

检查目标：角色、阶段与例外条件是否分别表达；标题能否得到证据支持；每项改动是否解释机制；去掉颜色后仍能理解主次；是否保留必要的限制条件。

## 五、形成自己的方法库

可迁移的是问题到证据、证据到取舍、取舍到实施的连接，以及对应这些关系的页面表达。灯塔工厂、OEE、IT/OT、特定岗位和制造收益区间属于领域内容，换主题时必须重建。

样本也不是无误的定稿规范：898025 p17标题与正文存在疑似沿用不一致，部分文件保留占位符和草稿标记。训练时应练习发现这些问题。以“我能解释、能重做、能指出适用边界”为学会的标准，再用新主题检验Skill能否帮助形成清楚、可信、可执行的报告。
