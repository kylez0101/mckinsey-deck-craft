# 视觉系统：先选择分析关系，再确定版式

本规格依据用户提供的9份PPTX、主题/母版元数据和实际预览归纳，不代表麦肯锡全部内部设计规范。页码指从封面开始的文件页序。下文明确区分“样本观察”和“新主题建议”；后者是可调整起点，用户模板、实际内容和阅读场景优先。

## 画布与页面骨架

**本用户封面覆盖规则（2026-10-23）。** 完整报告使用用户提供的[深蓝纹理背景](../assets/brand/cover-background.jpg)，保持原色与比例，封面全部文字为可编辑白字。旧麦肯锡线条封面只保留为历史学习材料，不用于新成品。实现见[固定封面模板](editable-templates.md#固定封面)。

**样本观察。** 9份均为16:9。前8份为13.3333×7.5英寸，912721为13.0677×7.3507英寸。878538 p28、39标题框x=0.6067、宽12.12英寸，左右边界约距画布4.55%；912721 p22也有相近比例。组内坐标不能直接视作全局坐标。

多数正文页采用左上标题、标题下细灰线、正文、底部来源与页码的骨架。常见分隔线约在页面高度17%处，页脚线约94%处，但封面、目录、三行标题和深色侧栏有例外。标题与表格、图表优先对齐到共同边界，正文根据任务变成单图、多列、矩阵、泳道或时间轴。

**新主题建议。** 无其他品牌要求时，采用16:9，先以左右4.55%边距建立约90.9%宽内容区。本用户要求整套有封面、标题尽量单行；先压缩标题，把解释放入正文，再根据实际行高确定正文起点。正文大体占页面中段，页脚独立。不要把所有页面强制放进同一列数。先保证阅读顺序和对齐，再决定拆页或删减；缩字号应晚于内容取舍。

## 字体与层级

**样本观察。** 9份主主题的major字体为Georgia，minor为Arial；前8份slideMaster1标题默认样式为25pt，912721为24.5pt。实际页面存在局部覆盖，例如878538 p28、39标题显式23pt，879680 p7的局部文字含12、16、20pt，878538 p39密集路线图有8pt文字。XML频次包含继承与覆盖之外的局部记录，不能据其推出完整的已解析页面样式。字体名称只表示元数据，不保证兼容渲染器逐像素还原原生字体。

**新主题建议。** 保留“衬线标题、无衬线正文”的层级关系时，先核实实际字体可用性。中文正文采用可获得、字形清楚的中文字体；标题是否采用宋体等衬线字形，应结合屏幕、字重与品牌测试，不把Georgia套在所有中文字上。本用户已反馈中文初版字号过大、页面拥挤，优先从下文阅读配置试排，投影场景另做可读性检查。字号不是样本统一标准，正文过多就重写或拆页。来源小字可弱化，影响判断的限定条件应靠近相关图表并保持可读。

标题形式随页面职责选择：发现页表达得到支持的判断；目录、定义、方法设置页可以用主题短语；操作手册可以用明确行动。890391 p11是框架总览，910309 p6–18有行动指导，912721 p10–16多为交付物与示例标签，无须全部改成强结论句。

## 图表与交付检查

1. 先写图表要回答的问题，再选择比较、分布、趋势、关联或流程结构。放大数字时保留对象、指标、单位、时间、基准和结果状态。
2. 图例靠近证据区；需要跨页比较时，单位、刻度、类别顺序及必要颜色保持一致。相关性、模型表现和变量重要性不能直接写成因果。
3. 主图、解释和标题须支持同一判断。截图可说明交付物形态，核心数据图表、表格及用户要求可编辑的图示应使用原生可编辑对象。
4. 来源与页码进入页脚或备注；决定结论成立的假设应在结论附近说明，不藏在难读脚注里。检查目录、当前阶段提示和正文编号一致。
5. 全尺寸检查每页，再看整套缩略图的密度与节奏。中文要实际检查换行、标点、数字和英文缩写，不能按原英文字符数机械回填。
6. 新作品采用用户自己的标识和素材。学习字体层级、对齐、色彩和论证结构，不默认复制官方Logo、合作方徽标、人员头像或专有字体。

兼容预览可能出现缺图、连线回退或字体替代。894149 p31曾无法兼容渲染，部分嵌入图也出现显示缺失；这些应回看源文件确认，不能作为设计规律。实际交付必须说明影响使用的差异，不能用“导出成功”替代视觉检查。

## 中文阅读配置

在1280×720画布上，常用起点为Songti SC标题、Arial Unicode MS正文、约4.5%侧边距。正文标题31px（约23.25pt）尽量单行，常规正文19–20.5px，表格约19–20px，封面短标题48px。这是阅读版起点；按字体、内容和距离复核，投影版另做可读性检查。

横线为主的开放表格、方案矩阵、职责表、评分卡、排期和预算明细按关系选择。单色图标需有明确语义和可追溯来源，不为填空添加。合计与分项用字重、浅底和缩进区分；大数字保留额度、目标或测算状态。

图表先检验能否解释差值、下行风险、资源瓶颈或代价。推荐、端点和扣减有依据才强调，优先直接标注，减少图例往返。零点标签、相邻点、绘图区外标注、表格末行与页脚均需留出净空。具体选型与编辑规则见[专业图表](professional-chart-design.md)，主题覆盖见[主题系统](theme-system.md)，交付动作见[成品检查](production-checks.md)。
